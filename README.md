# STM32 Nucleo-L152RE Feature Tour Study

Example proof of concept applications tested on the board based on the API document UM1816 covering HAL drivers. \
It can be thought of as a tour of the L152 hardware. Compared to examples presented with the firmware support libraries \
these are hand-made and the firmware examples haven't been taken as reference.

Refer to individual README files in project folders for more information.
