# STM32 Nucleo-L152RE Feature Tour Study

Example proof of concept applications tested on the board based on the API document UM1816 covering HAL drivers.
It can be thought of as a tour of the L152 hardware. Compared to examples presented with the firmware support libraries
these are hand-made following the Keep it Simple and Stupid principle to demonstrate most usual scenarios of peripheral use.

Examples were pregenerated with the configuration tool STM32CubeMX. Configuration files from the tool
can also be found in example folders.

Refer to individual README files in example folders for more information.
