# STM32 L152 System Driver
The code uses a small portion of System Driver API, ignoring initialization functions, because they're \
pretty much covered by the stub generated by CubeMX bootstrapping app.

## Flow
* Every second the chip will print tick value to the console via UART.
* Pressing the B1 button on the NUCLEO board will toggle the tick count on and off.
* When tick engine is suspended, tick value printing pauses.
* When tick engine is resumed again, tick value printing should continue form where it was.
