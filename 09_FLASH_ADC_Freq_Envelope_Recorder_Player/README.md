# FLASH ADC Envelope Recorder with Replay and Load from Flash

An ADC envelope of a certain length can be recorded at a rate and replayed. The envelope can also be saved to flash memory for persistance and reloaded from flash.

Four buttons are used in interrupt pull-up mode for Record, Replay, Save and Load functionality.

An Led&Key serial module is used as display for values and an LED progress bar as shown in the picture.
